# HostProof Tools Site

Static website for HostProof Tools, including a free same-day turnover readiness calculator for short-term rental hosts.

## Free Tool

Same-Day Turnover Readiness Calculator:

https://balllba.github.io/hostproof-tools-site/same-day-turnover-readiness-calculator.html

The calculator helps a host or operator decide whether a same-day turnover is guest-ready before check-in by checking:

- final room photos
- bathroom and kitchen proof
- starter supplies
- laundry and linens
- open issue notes
- final ready confirmation

## Privacy

The calculator runs in the browser and does not require login. It does not store submitted data on a server.

## Hosting

This site is static and can run on GitHub Pages or any static host.
